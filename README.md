# YVR Bridge

**跨平台 XR 应用移植与兼容项目**

YVR Bridge 是一个面向 Android XR 设备的跨平台应用兼容与移植项目，旨在降低不同 XR 平台之间的应用兼容障碍。

项目主要针对原本为 Meta Quest、PICO 等平台开发的 XR 应用，通过 OpenXR 接口适配、原生动态库代理和应用级补丁，使这些应用能够在 YVR（奇遇 VR）等其他 Android XR 设备上运行。

项目采用可扩展的应用适配方案，允许针对不同应用的兼容问题开发独立补丁，而不局限于某一款应用或某一种修复方式。

## 项目特点

- 跨平台 XR 应用兼容与移植
- 基于 OpenXR 的接口适配
- 原生动态库代理与补丁机制
- 针对不同应用的独立兼容方案
- 支持 DIY 构建和自定义补丁
- 持续增加设备及应用适配案例
