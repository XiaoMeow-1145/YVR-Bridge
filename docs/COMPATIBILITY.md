# 当前应用适配情况

本文档记录 YVR Bridge 对不同 XR 应用的适配进度。状态以实际设备测试为依据，并应随应用版本、系统固件和补丁变化持续更新。

## 状态说明

| 状态 | 含义 |
|---|---|
| 已验证 | 已在注明的设备和版本上完成对应功能测试 |
| 部分兼容 | 已有部分功能可用，但仍存在已知问题 |
| 测试中 | 正在进行适配或验证 |
| 未验证 | 尚无足够的实际测试结果 |
| 不兼容 | 已确认在指定环境下无法正常工作 |

|---|---|---|---|

## 测试原则

- 明确区分应用启动、进入 XR、显示正常和完整功能可用。
- 每条结论都应关联应用版本、设备型号和系统版本。
- 不同来源平台的应用应分别记录。
- 固件或应用更新后，必要时重新验证。
- 对尚未测试的功能标记为“未测试”，不要推断为可用。

## 新增适配案例

新增应用案例时，请同时提供测试环境、适配补丁、验证项目、结果及已知问题。更详细的问题处理方法请查看 [TROUBLESHOOTING.md](TROUBLESHOOTING.md)。
